llm.css: Styles for LLMs and agents

llm.css is a small set of CSS styles that you can give to an LLM or coding agent to steer the way it styles a web page. You can see what it looks like on our demo page. You can also visit the GitHub repo.

Origin

I created llm.css by asking ChatGPT to create a set of CSS variables based on Tailwind. Then I asked it to create a set of rules using those variables. The project was inspired by Tailwind, Open Props, and various classless and class-light CSS frameworks.

Usage

I think there are 4 ways you can use this project:

  1. At a minimum, I think you can probably give an LLM just the CSS variables and that should help steer it.
  2. If you want to steer it even more, give it the full CSS code.
  3. You can also change the values for the CSS variables or add more variables if you want to customize the way it looks.
  4. If you just want to take this idea as inspiration, you're free to come up with your own CSS variable names, values, and rules.

Code

Here are the core CSS variables:


:root {
  /* Fonts */
  --font-sans: ui-sans-serif, system-ui, sans-serif;
  --font-mono: ui-monospace, SFMono-Regular, Menlo, monospace;

  /* Typography */
  --text-sm: 0.875rem;
  --text-base: 1rem;
  --text-lg: 1.25rem;
  --text-xl: 1.5rem;
  --leading-tight: 1.2;
  --leading-normal: 1.5;

  /* Spacing */
  --space-1: 0.25rem;
  --space-2: 0.5rem;
  --space-4: 1rem;
  --space-6: 1.5rem;
  --space-8: 2rem;

  /* Tailwind Colors */
  --color-bg: #ffffff;
  --color-surface: #f9fafb;
  --color-text: #111827;
  --color-muted: #6b7280;
  --color-border: #d1d5db;
  --color-primary: #475569;
  --color-accent: #475569;

  /* Radius */
  --radius: 0.5rem;

  /* Shadow */
  --shadow-sm: 0 1px 2px rgba(0, 0, 0, 0.06);

  /* Borders */
  --border: 1px;

  /* Layout */
  --container: 960px;
}

CDN

You can also use the file through a CDN. If you're using it with an LLM, you still might want to give it the code so it knows what's inside (or you might want to at least mention it's a class-light CSS framework). If you're using it with an agent, you might want to have it fetch the file and read the contents of the file first before using it.

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/jhonkaman/llm-css/llm.css">
